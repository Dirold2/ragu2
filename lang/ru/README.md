# RAGU2

Discord-музыкальный бот с интеграцией Яндекс.Музыки, обработкой аудио и локализацией.

[English](../../README.md), [__Русский__](./README.md)

## Возможности

- **Воспроизведение** — play, pause, skip, shuffle, очередь, loop
- **Эквалайзер** — басы (`-20`–`20`), высокие (`-10`–`20`), компрессор
- **Громкость** — регулировка с плавным fade in/out
- **Моя волна** — бесконечное радио по последнему треку
- **История и топ** — недавние и популярные треки
- **Управление очередью** — просмотр, очистка, авто-переход
- **Переподключение** — автоматическое восстановление при обрывах сети
- **Локализация** — английский и русский
- **Система плагинов** — расширяемая поддержка музыкальных платформ

## Поддерживаемые платформы

| Платформа | Статус |
|-----------|--------|
| Яндекс.Музыка | ✅ |

## Установка

```bash
git clone https://github.com/dirold2/ragu2.git
cd ragu2
npm install
```

Создайте `.env`:

```env
DISCORD_TOKEN=""          # https://discord.com/developers/applications
BOT_LOCALE="ru"           # en / ru
FFPROBE_PATH=""           # опционально, путь к ffprobe
YM_USER_ID=""             # https://mail.yandex.ru/
YM_API_KEY=""             # https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d
```

## Запуск

```bash
# разработка
npm run dev

# продакшн
npm run build && npm start

# через PM2
npm run pm2:start
```

## Команды

| Команда | Описание |
|---------|----------|
| `/play <запрос>` | Поиск и воспроизведение трека |
| `/pause` | Пауза / продолжить |
| `/skip` | Следующий трек |
| `/volume <0–100>` | Громкость |
| `/equalizer <басы> <высокие> <компрессор>` | Эквалайзер |
| `/loop` | Зациклить очередь |
| `/shuffle` | Перемешать очередь |
| `/queue` | Показать очередь |
| `/wave` | Моя волна |
| `/other history` | Недавние треки |
| `/other top` | Популярные треки |
| `/other queuedel` | Очистить очередь |
